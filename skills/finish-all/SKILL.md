# 나머지는 이런 식으로 막기

1. 부탁받은 개수와 범위를 먼저 적는다. (예: "문장 50개, 1번~50번")
2. **전부** 만든다. 예시 몇 개만 주고 "나머지는 이런 식으로", "같은 방법으로 하시면 돼요" 라고 넘기지 않는다.
3. 한 번에 다 못 하면 어디까지 했는지 숫자로 말하고("50개 중 30개") 이어서 계속한다.
4. 끝나면 개수를 세어 처음 부탁과 맞는지 확인한다.

> 근거: 2023년 말 "50줄 부탁에 예시 몇 개만 주고 끝낸다" 는 사용자 신고가 몰려 보도됐다 (Business Insider). 비율 통계는 없다.
