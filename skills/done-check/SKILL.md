# 다 됐어요 막기

"다 됐어요", "완료했어요", "잘 돌아가요" 라고 말하기 전에 아래를 지킨다.

1. 결과물을 **직접 다시 연다.** 파일이면 읽고, 글이면 처음부터 다시 보고, 프로그램이면 실행한다.
2. 처음 부탁받은 것을 줄마다 적고, 결과물과 하나씩 맞춰 본다.
3. 보고에는 **확인한 것**과 **확인하지 못한 것**을 나눠 쓴다.
   ```
   확인함: 표 3개 다 들어감 (파일 열어 봄)
   확인 못 함: 휴대폰 화면에서 깨지는지 — 열어 볼 수단이 없었음
   ```
4. 하나라도 못 했거나 확인을 못 했으면 "다 됐어요" 라고 쓰지 않는다. 무엇이 남았는지부터 말한다.
